# POPART.love

Static site for popart.love. Same section structure as bitpopart.com (News, Artist, PopUp, Cards, Stickers, Prints, Shop), with its own Love / Freedom / Joy pop art look and no Bitcoin, Nostr or AI theming.

## Folder

```
POPARTlove/
  build.py            generates every page, the SVG art, sitemap, robots, _headers, CNAME
  assets/css/style.css
  assets/js/site.js   theme toggle, mobile menu, newsletter form
  assets/img/         logo, favicon, placeholder artworks (SVG), cards/ (example card WebPs)
  assets/fonts/       self-hosted Bangers, Barlow Condensed, Space Mono, Inter
  index.html, cards/, popplay/, stickers/, prints/, shop/, news/, artist/, popup/, 404.html
```

## Card Maker

`cards/maker/index.html` is the POPART Card Maker, a single self-contained tool page (it is not generated by `build.py`, edit the file directly). It loads Google Fonts and jsPDF from cdnjs. The six example cards in `assets/img/cards/` were rendered with the maker's own drawing code. The "write card text from the art" button only works inside Claude, so it is hidden on the site.

## Adding a new card

1. Make the card in the Card Maker and export the front and the back as images (WebP, 600x840 works well).
2. Put it in `assets/img/cards/` (for example `my-card.webp` and `my-card-back.webp`). Visitors flip the card between front and back.
3. Add one entry at the top of `data/cards.json` (file, name, theme, series, rarity, run, blurb).
4. Run `python3 build.py`, commit and push. The card appears on the Cards page (the first three also show on the home page).

## Importing cards from the Card Maker

The Card Maker has a "Send cards to popart.love" panel that saves a site file (`popart-site-cards.json`) with the front and back pictures and the details of each card. Import it with:

```
python3 import_cards.py popart-site-cards.json
python3 build.py
```

This writes the pictures to `assets/img/cards/`, adds the card to `data/cards.json` (or updates it, keeping its status and stock) and the card then shows on the Cards page and in the Verify my card list.

## Card stock and the admin

- Each card in `data/cards.json` also has `online`, `offline` and `url` (external shop link, https only). Cards show a Buy online chip (to that link) and an At events chip (to the PopUp page). The admin edits all of these.
- Each card in `data/cards.json` has `status` (`available`, `sold-out`, `coming-soon`) and `left` (copies remaining, or `null` when not tracked). These are the defaults baked into the pages.
- Live stock is kept in Cloudflare KV and served by `worker/index.js` at `/api/stock`. The card pages fetch it on load and override the defaults.
- `/admin/` looks like a 404 page to everyone. The editor only appears when the Nostr extension signs in with the owner key (and an Admin menu link then appears in that browser). Saving sends a NIP-98 signed Nostr event; the worker only accepts the key in `ADMIN_PUBKEY` (`wrangler.jsonc`).
- Deploy with `npx wrangler deploy` (the KV namespace is created on the first deploy).

## Verify my card

`/verify/` checks the card code from the back of the card (see Per-copy verify codes below), not the printed number. The sold list is kept in Cloudflare KV and edited in `/admin/` (Sold serials column, like `1-5, 7`).

## Edit and rebuild

Content lives in `build.py` (page text, `ARTWORKS`, `EXAMPLE_CARDS`, `SHOP_ITEMS`, `NEWS_ITEMS`). After a change:

```
cd POPARTlove
python3 build.py
python3 -m http.server 8765   # preview at http://127.0.0.1:8765
```

### Per-copy verify codes
Each numbered copy can carry its own code, printed on the back of the card and on the Card Maker certificate and mount card. The code is the first 40 bits of HMAC-SHA256(`CODE_SECRET`, `<card file>:<serial>`) written as 8 letters and digits, shown as `K7QM-2XP9`. Set the same secret in the Card Maker (Secret verify key field) and on the site: `wrangler secret put CODE_SECRET`. `/verify/` asks for the code only (no serial): `/api/verify?code=..` makes the codes of all numbered copies from the secret, finds the match and answers card, copy number, whether it is on the sold list and how many times the code was checked. 10 tries a minute per visitor. Without `CODE_SECRET` it answers 503. The card file is the site card id, for example `heart-holder`. Never commit the secret.
